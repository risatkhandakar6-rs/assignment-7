# KeenKeeper 🌿

**KeenKeeper** is a personal relationship-tracking app that helps you stay connected with the friends who matter most. Browse your friend list, log quick check-ins (calls, texts, or video chats), and visualize your interaction habits — all in one clean dashboard.

🔗 **Live Site:** [https://your-netlify-link-here.netlify.app](https://your-netlify-link-here.netlify.app)

---

## 🛠️ Technologies Used

- React.js / Next.js (App Router)
- Tailwind CSS + DaisyUI
- Recharts
- React Context API
- react-toastify
- react-icons

---

## ✨ Key Features

1. **Quick Check-In & Timeline Logging** — Log a Call, Text, or Video interaction with a friend in one click, saved instantly to the Timeline with the date.

2. **Filterable Timeline** — Filter your interaction history by type (Call, Text, or Video) using a simple dropdown.

3. **Friendship Analytics Dashboard** — A pie chart on the Stats page shows the breakdown of your Call, Text, and Video interactions at a glance.
